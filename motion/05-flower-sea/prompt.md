# 05 · 彩色的时间长河 · 月上泪湖（Tear Lake）

> 参数表是唯一事实来源。改动画先改本表，再同步 `index.html` 的 `CONFIG`。

## 效果概述

**画面基准 9:16 竖屏**（仍全屏自适应，`windowResized` 不错位）。
夜空深邃，**右上方悬一轮明亮的月牙（弯月如小船，两角朝上）**；**女孩纯黑剪影
（使用素材图 girl-silhouette.png，白底用 multiply 混合隐去）抱膝坐在月牙上**，
面朝湖面。**下半画面是一片湖**——由歌词字符汇成的"时间长河"铺成的湖面：
字符按透视行排布（近大远小、近快远慢、近亮远暗），行色自远处冷蓝→近处暖金
渐变（"彩色的時間"），月下有一道碎金般的**月光倒影**。**湖底沉着一只平躺的
古典圆钟**（透视压扁为椭圆、双线表圈 + 12 刻度 + 时/分针，暖金微光、半透明
淹没感），恰好沉在月光光路中、泪落点的正下方——**泪落即落钟心**。**4.0s 一滴
泪凝上女孩眼角**——不停留，直接沿脸颊缓缓滑落 1.5s，离脸后以重力加速坠落 1.2s
（拉伸 + 拖尾，时间基准落湖）；**6.7s 泪落钟面**：溅起细珠、泛起
**错峰抖动、大小不一的扁椭圆涟漪**（噪声摆动，非机械正圆；涟漪只在湖面内）
自钟心荡开，**指针在 3s 内缓缓停摆**（"静止了所有的花开"）；随即**褪色前沿**
自钟心扩散——字符逐字灰化、**钟的刻度与指针按到钟心的距离逐圈染上空白**，
约 4.5s 后整湖与钟褪为灰白。落幕淡出无缝循环（16s）。**交互**：点击湖面落
"你的泪"——小溅珠 + 局部涟漪 + 局部褪色，数秒内愈合；若落在钟附近，
指针会短暂"卡壳"顿挫后恢复；唯有叙事那一滴的褪色与停摆不可逆。
左上角两句静态歌词，竖直排版（writing-mode: vertical-rl，列自右向左，DOM 层）。

## 时间轴

| 时刻 | 事件 |
|---|---|
| 0 ~ 0.6s | 开场自黑场淡入；月牙与女孩剪影显现，湖面字符流动（全彩），湖底沉钟指针开始走字 |
| 0 ~ 6.7s | **钟针匀速旋转**：分针 1 圈/循环（22.5°/s），时针 1/12 圈/循环；针尖搅动周围字符 |
| 1.2 ~ 3.0s | 左上角竖排歌词淡入（DOM 层） |
| 4.0s | **泪滴出现**（0.3s 淡入）即开始**沿脸颊缓慢滑落** slide 1.5s：垂直颊线（眼→颌边，x 不变），smoothstep 缓动 |
| 5.5s | **离脸坠落** fall 1.2s：初速继承滑落末速 + 重力匀加速（g 反解自落点，时间基准），垂直落体，拉伸 + 2 重拖尾 |
| 6.7s | **泪落钟心**：溅珠 8 粒 + 闪光环（钟面被瞬间照亮）+ 5 圈扁椭圆涟漪错峰扩散（自钟心荡开） |
| 6.7 ~ 9.7s | **指针缓缓停摆**（slowDur 3s，smoothstep 减速至 0）——"静止了所有的花开" |
| 6.7s 起 | **褪色前沿**（椭圆压扁 0.3）以 260px/s 自钟心扩散（软边 300px）；钟的刻度/指针按距钟心逐圈灰化 |
| ~11.5s | 整湖与钟褪为灰白（9:16 视口估算） |
| 6.7 ~ 10.7s | 涟漪各圈 ~2.4s 寿命内相继消散（扫过钟面时钟影折射轻晃）；环境碎纹持续生灭 |
| 14.8 ~ 16s | 落幕纱幕淡出（落款同步）→ 循环重置，湖重新全彩、指针归零重走，无跳变（纱幕遮蔽重置） |

## 场景布局

1. **天空**：竖向三段渐变（top→horizon→bot 中 horizon 以上段）；星尘闪烁；
2. **月牙**（离屏烘焙进背景）：圆 (mx,my,r) 先画到独立画布，被上移 cut×r、半径
   cutR×r 的圆挖去（destination-out）后合成到背景（避免挖穿天空渐变）→ 两角朝上
   的弯月；外圈径向光晕；
3. **湖**：y∈[horizon, H]；行 r 的 y = horizon + 湖深×(r/rows)^rowExp（近疏远密
   反转：近行距大）；字号/速度/明度随行深插值；字符 x = (x0 + speed×t) mod
   (W+2×margin) − margin（左→右）；
4. **月光倒影**：月下光路——30 条短横线，x 散布 ±spread(y)（上窄下宽），
   透明度随时间闪烁；
5. **女孩**：素材图 multiply 混合（白底隐去、黑形保留），座于月牙内弧
   （座点 = 圆心 + (dx, seatK)×r），面朝湖。

## 湖底沉钟

- **位置**：钟心 = 泪落点 (impX, impY)——泪落即落钟心，涟漪自钟心荡开；
  恰在月光倒影光路中；半径 = min(r×W, 湖深钳制)，压扁 squash 0.55 成椭圆
  （平躺透视），钟体完整没入湖面之下；
- **形制**：双线表圈（外圈 + 0.88 内圈，各 36 弧段逐段着色）+ 12 刻度
  （3/6/9/12 主刻度加长）+ 时针（0.45r）/ 分针（0.72r，带尾）+ 中心轴点；
- **淹没感**：整体 alpha 0.5 × 明暗呼吸（±0.15），暖金微光；表盘叠 0.22
  水色罩染；绘制顺序在月光倒影与字符湖**之前**（字符从钟面"流过"）；
- **走字与停摆**：指针角度由"有效走时"effT 累积（每帧 effT += dt×速度系数），
  分针 = effT/16×1 圈、时针 = ×1/12 圈；速度系数：6.7s 前 = 1，泪落后
  slowDur 3s 内 smoothstep 1→0（停摆后凝固不动）；循环重置时 effT 归零
  （落幕纱幕遮蔽归零瞬间）；
- **四处交互**：
  1. 泪落钟心——闪光环同时照亮钟面（0.6s alpha 提升）；
  2. 涟漪扫过钟面——折射晃动 wobble px（环半径扫过 0.6×clkR 处达峰）；
  3. 指针搅动——钟周 1.15×clkR 内字符受切向微推（stir px × 速度系数），
     停摆后搅动消失；
  4. 交互泪落钟附近（1.4×clkR）——指针卡壳：1.5s 内速度系数降至 0.3 后恢复；
- **褪色同步**：每个刻度/弧段/指针按到钟心的距离套用同一 drain 前沿公式
  （dy/0.3 压扁空间），颜色 暖金→灰、alpha 再 ×0.55——钟与湖一起"染上空白"。

## 泪落三段式（滑落 → 坠落 → 涟漪褪色）

1. **滑落**（at → at+slide，不停留）：0.3s 淡入即开始移动，沿**垂直颊线**
   P0(眼)→P1→P2(颌边)（x 恒等于眼位，行程 = 脸长 0.06×图高），smoothstep
   缓动（慢出慢入）；泪珠小而收敛（光晕 glowK 0.5），不遮挡剪影、无光线拖尾；
2. **坠落**（slide 段后 fall 秒）：初速 v0 = 滑落行程/slide×0.55 继承末速，
   **重力匀加速** y = v0·t + ½·g·t²，g = 2(D−v0·T)/T² 反解自落点——
   既符合重力规律又保证时间基准落地；垂直落体，无水平分量；
   拉伸 scaleY=1+stretch×k，2 重拖尾（各退 0.045s），全光晕；
3. **涟漪**：溅珠 8 粒 + 闪光环 + count 圈**扁椭圆**（squash 0.3）错峰扩散，
   每圈半径叠噪声摆动 r(θ)=r×(1+wobble×noise(θ))，间隔带随机抖动；
   **涟漪与闪光裁剪在湖面矩形内**（y ≥ horizon），不会进天空；
   字符推挤在压扁空间计算（d 用 dy/squash），推出方向还原；
4. **褪色**：椭圆前沿 drainR = speed×(t−impact)，sat = sstep(drainR−soft, drainR, d_ell)；
   交互泪：局部 sat 凹陷 × 愈合系数，与叙事 sat 取 min。

## 性能优化

1. 字形精灵缓存：唯一（字符×行色）组合预渲染彩色+灰色两版（17px 基准），
   逐帧 drawImage 缩放（褪色期最多 2 次 drawImage/字）；
2. 天空+月牙+湖底渐变离屏缓存，仅 resize 重绘；女孩素材预加载；
3. 涟漪 ≤5 圈逐顶点描边（每圈 40 顶点）；碎纹 40 条 arc；目标 60fps。

## 偏离规范的说明

AGENTS.md 约定"诗句用 DOM 层排版"，但湖中字符需要逐字流动、透视变换、被涟漪
推挤、逐字褪色，DOM 无法实现，故湖中字符用 canvas 绘制（同 04 偏离理由）。
左上角竖排静态歌词与左下署名不需要逐字动画，**按规范回归 DOM 层排版**。
