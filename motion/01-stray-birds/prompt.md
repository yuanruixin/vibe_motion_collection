# 「飞鸟集 · 流光」动画生成提示词（优化版）

> 用途：将本提示词完整粘贴给任意 AI 编程助手，即可复现该动画。按「可调参数」表修改数值即可衍生新版本。暂不包含音频。

---

## 提示词正文（直接复制使用）

### 1. 角色与目标

你是一位精通生成艺术（Generative Art）的前端工程师，参考 OpenProcessing 热门作品的视觉技法，用 **p5.js** 制作一个诗意动画单页应用「飞鸟集 · 流光」。

**硬性约束：**
- 输出**单个 `index.html` 文件**，浏览器直接打开即可运行（联网加载 CDN）
- p5.js 1.11.3（`https://cdn.jsdelivr.net/npm/p5@1.11.3/lib/p5.min.js`）
- 字体：Google Fonts 的 **Noto Serif SC**（中文衬线）+ **Cormorant Garamond italic**（英文）
- 画布全屏自适应（`windowResized` 处理），深色底 `#0a0e21`
- **总时长 16.0 秒，无限循环**，纯自动流转，无需用户操作即可完整观看

### 2. 视觉基调（暮色流金）

采用 OpenProcessing 流行技法组合，画面要求"从不喧闹、永远微动"：

- **流场粒子**：Perlin 噪声驱动，粒子留下渐隐的发光轨迹，重叠处使用 ADD 混合模式产生泛光
- **分层渲染**：天空渐变层 / 发光轨迹层 / 主体层 / 胶片颗粒层各自独立合成，画面有空气感
- **暮色 HSB 渐变**：暖金 → 绯红 → 黛蓝的低饱和黄昏天空，色相随时间缓慢漂移
- **胶片质感**：全程叠加动态噪点颗粒 + 轻微暗角（径向渐晕），让画面像胶片而非屏幕
- 主体色板：
  - 花火 `#ffd27a #ff9e6b #ff7a8a #e8c37a #ffb56b`
  - 秋叶 `#c98a3d #b5652f #d9a441 #a05a2c #8a5a34`

### 3. 四幕场景与诗句（时间分配核心）

共 6 句诗，**每句完整可见约 2 秒 + 0.4s 淡入 + 0.4s 淡出**，幕长按诗句数分配：

| 幕 | 时长 | 诗句（中 / 英） | 视觉实现 |
|---|---|---|---|
| 壹 · 飞鸟 | 2750ms（1句） | 夏天的飞鸟，飞到我的窗前唱歌，又飞去了。<br>Stray birds of summer come to my window to sing and fly away. | 暮色天空，噪声流场驱动的鸟群划出渐隐发光弧线，掠过即逝 |
| 贰 · 夏花秋叶 | 5250ms（2句，第2句 t=2600ms） | 使生如夏花之绚烂 / Let life be beautiful like summer flowers. → 死如秋叶之静美 / And death like autumn leaves. | 前半幕：粒子在画布上快速连放"绽放"成花（easeOutCubic 生长）；后半幕：黄叶随风飘落，**以 deltaTime 为基准在 1.05~1.4s 内落地**，落地化为墨点晕开 |
| 叁 · 痕迹 | 2750ms（1句） | 天空中没有留下鸟的痕迹，而我已飞过。<br>I leave no trace of wings in the air, but I am glad I have had my flight. | 一只孤鸟贯穿整幕横越长空，身后光痕随幕推进加速消散殆尽 |
| 肆 · 海与天 | 5250ms（2句，第2句 t=2600ms） | 海水呀，你说的是什么？是永恒的疑问。<br>What language is thine, O sea? → 天空呀，你回答的话是什么？是永恒的沉默。<br>What language is thy answer, O sky? | 层叠正弦海浪起伏，月光在海面碎成波光；幕中一只归鸟掠向海平线，衔接回第一幕形成循环闭环 |

### 4. 诗句排版（DOM 层，非 canvas 绘制）

诗句用 DOM 元素叠加在 canvas 之上（`pointer-events:none`），便于精细排版：

- 中文主句：Noto Serif SC 300，`clamp(20px, 2.6vw, 34px)`，字距 `0.32em`，行高 2.1，居中，暖白色 `#f5ead8`，柔和金色 text-shadow 发光
- 英文副句：Cormorant Garamond 斜体，小一号，透明度 55%，位于中文下方 2.4vh
- 顶部固定题名「飞 鸟 集 · 流 光」+ 英文小字，字距 0.9em
- 底部四个幕码（壹/贰/叁/肆）指示当前幕
- 整体上移 `translateY(-7vh)` 避开画面视觉中心
- 诗句容器避开画面主体：花开位置随机时若落在中央诗句区则镜像避开

### 5. 交互

- **鼠标移动 = 风场**：位置与速度映射为风力向量，扰动鸟群轨迹、花瓣与落叶
- **点击 = 疾风（gust）**：短促强风，扰动所有粒子后自然衰减
- 首次进入显示操作提示，数秒后自动淡出

### 6. 质量与验收标准

- [ ] 16.000s 整轮回（2750+5250+2750+5250），循环无跳变
- [ ] 幕间黑场过渡约 0.34s，不挤占诗句停留时间
- [ ] 六句诗每句停留时长一致（约 2s），淡入淡出对称
- [ ] 60fps 流畅（粒子数量按屏幕面积缩放）
- [ ] 夏花绽放 → 秋叶落地化墨的完整叙事必须在幕二结束前完成
- [ ] 归鸟飞向海平线的时机使幕四自然衔接回幕一
- [ ] 窗口缩放后布局不错位

### 7. 可调参数表（衍生新版本时改这里）

| 参数 | 当前值 | 说明 |
|---|---|---|
| `SCENES[].dur` | 2750 / 5250 ms | 各幕时长，总和必须 = 16000 |
| `verses[].t` | 0 / 2600 ms | 幕内第二句的出现时刻 |
| 诗淡入/淡出 | 400ms | 对称缓动 |
| 幕间黑场 | 340ms | 场景切换遮罩 |
| 叶落地时长 | 1.05~1.4s | deltaTime 基准 |
| 花期窗口 | 幕前 45% | 持续绽放新花 |
| 色板 | 暖金/绯红系 | 换成水墨（宣纸底+墨色+朱砂）即得水墨版 |
| 循环方式 | 无限循环 | 改为播完停在末幕即"放映版" |

## 复现步骤建议

1. 将上述第 1~6 节整体粘贴给 AI 助手，要求输出单文件 `index.html`
2. 用本地服务打开（`python3 -m http.server`），按第 6 节验收清单逐项核对
3. 重点实测：在 t=1.1 / 4.4 / 7.7 / 11.0 / 14.3 / 17.6 秒采样诗句文本，应依次为六句诗且 17.6s 回到第一句
4. 如节奏不符，只调整第 7 节参数表中的数值

## 本次迭代的经验教训（已固化进提示词）

- 动画节奏必须**所有时间参数联动修改**（幕长、诗句 t、淡入淡出、粒子寿命、飞鸟速度），只改幕长会画面叙事与诗句错位
- 落叶等"必须完成的动作"要用**时间基准（deltaTime 映射）**而非物理速度，保证短幕内必定落地
- 诗句用 DOM 层而非 canvas 文字，排版质量高一个档次
- 中文字距（letter-spacing）会让末字后多出空隙，需用等量 `text-indent` 平衡
