# 牵丝之城 · City of Tethers

> 他从郊区一路狂奔进城，放慢脚步散步、环顾四周；
> 走着走着，高楼窗口开始伸出丝线，一条、又一条，缠住他的背与肩。
> 他挣扎着向深处那扇暖光小窗挪动——看得见家，走不到家。
> 16s 无限循环：世界是一段"郊区→城市"的单向旅程（转场天然丝滑），
> 末幕 1.3s 与"1.3s 前（t−16）的画面"交叉溶解，无缝回到郊区奔跑。

## 已确认的创意决策（v2 修订）

| 项 | 结论 |
|---|---|
| 叙事 | 三幕：郊区快速奔跑 → 到城市先散步、环顾 → 丝线逐渐伸出缠住他，挣扎极慢前进 |
| 转场 | 丝滑：世界内容沿旅程轴连续变化（楼房渐高渐密），速度用 smoothstep 过渡 |
| 镜头 | 不要大抖动：微晃幅度 ≤1.3px（奔跑时）/ ≈0.3px（散步与挣扎时） |
| 建筑 | 立体感：楼体 = 正面 + 临街侧面（盒体投影），侧面受光略亮；郊区小屋带坡屋顶 |
| 人物 | 正常人比例（rz=5.2，约 130px / 13.5% 画面高）；参考图剪影：大圆头、细长大衣身、细腿，纯黑 #04060d |
| 小窝 | 灭点附近暖窗小屋（世界 z=52），郊区时不可见，进城后自然显现并呼吸闪烁 |
| 文字 | 纯画面无文字、无署名 |

## 分幕与时间参数（唯一事实来源，改动画先改此表）

| 幕 | 时间 | camZ(t) | 人物状态 |
|---|---|---|---|
| 1 郊区奔跑 | 0 – 4.5s | 0 → 30（6.67 u/s 匀速冲刺） | 奔跑：步频 2.2 步周期/s、高抬腿、摆臂幅度 ×1.8、前倾 +0.08u |
| 转场减速 | 4.5 – 6.0s | 30 → 34（smoothstep） | 步频 2.2→0.85 平滑衰减，runAmt 渐隐 |
| 2 城市散步 | 6 – 10.5s | 34 → 40（1.33 u/s） | 散步 + 环顾：头左右转（周期 3.6s，包络 6→10.5s 渐入渐出） |
| 3 缠丝挣扎 | 10.5 – 16s | 40 → 41.3（≈0.24 u/s 极慢） | 丝线 10.0s 起逐条伸出（每 0.22s 一条）；surge ±0.30（0.55Hz 前拱→拖回）；hunch 渐进加深 |
| 循环闭合 | 14.7 – 16s | — | 与 scene(t−16) 交叉溶解（globalAlpha 0→1），回到郊区奔跑 |

## 关键函数（纯时间函数，交叉溶解保证闭环）

- `camZ(s)`：分段定义；s<0 时按奔跑速度向过去延伸（郊区物件周期延绵），供叠化层使用。
- `stridePhase(s)`：步相位累积（奔跑 2.2 / 过渡积分 / 散步 0.85 / 挣扎 0.5 步周期每秒）。
- `runAmt = 1−ss(4.5,6,s)`；`struggleAmt = ss(10.5,12.5,s)`；环顾包络 `ss(6,7,s)·(1−ss(9.8,10.8,s))`。
- 丝线：`taut = struggleAmt·(0.5+0.5·sin(2π·0.55·(s−10.5)−0.9))`，绷紧更亮更挺，松弛下垂晃动。
- 镜头微晃：幅度 `(0.3+0.7·runAmt)·0.8px`，两个自由频率正弦叠加。

## 立体感做法

- 楼体：正面（暗）+ 临街侧面（亮 1.35×），侧面为盒体棱边在 rz 与 rz+d 两景深间的投影四边形。
- 郊区小屋：正面 + 山墙屋顶三角 + 侧墙面 + 屋面四边形，暖窗 2–3 扇微闪烁。
- 远楼（z 46–58）：进入视距（rz<38）时随 fade 淡入，无闪现。

## 循环安全约定

- 场景是时间 s 的纯函数 `drawScene(s, alpha)`；s<0 有定义（郊区向过去延伸）。
- 末幕 `t∈[14.7,16]`：先画 `scene(t)`，再以 alpha 0→1 叠画 `scene(t−16)`；t=16 时画面≡scene(0)，无缝。
- 自由频率允许使用（闭环由叠化保证，不再要求 `TWO_PI·k/16`）。
- 调试：`?t=8.0` 冻结任意时刻截图验收。

## 验收清单

- [ ] 0–4.5s 郊区：小屋/树/路灯飞速后退，奔跑姿态明确（高抬腿、摆臂、前倾）
- [ ] 4.5–6s 减速丝滑，无速度跳变；楼房逐渐变高变密
- [ ] 6–10.5s 散步，头部左右环顾（渐入渐出）
- [ ] 10s 起丝线逐条伸出（不一次全出现），缠到背/肩/胯；绷紧/松弛随挣扎切换
- [ ] 挣扎时背景几乎不动，人物 surge 前拱→拖回
- [ ] 楼体有侧面立体感；小屋有屋顶；人物比例正常（≈130px）
- [ ] t=16 → t=0 叠化无跳变；暖窗小屋进城后可见并闪烁
- [ ] 无大抖动、无署名；缩放不错位；60fps
