# 04 · 环形诗句 · 蒲公英的约定（Dandelion Orbit）

> 参数表是唯一事实来源。改动画先改本表，再同步 `index.html` 的 `CONFIG`。

## 效果概述

新海诚风蓝色天空（三段渐变 + 顶部暖光晕）中，一株蒲公英的**白色根茎从左下画外
伸出**，白色绒球（圆点）从左下方沿茎**移动到画面中央**（途中轻微飘动，且**少量
字符在移动途中即开始飘散**）。预设文字（《蒲公英的约定》歌词 + 英文自译补充）
按**多层同心圆**环绕绒球排布，**每行自动重复铺满整圈**，**所有环同时淡入**，
行距**内紧外松递进**（内环可部分重叠），环间参差交错（随机起始角、径向抖动、
反向异速旋转），**每朵字符独立微微摇摆**。**右下角另有两句静态歌词**（DOM 层
排版，右对齐、字距疏散）：随开场淡入，落幕时与纱幕一起淡出。2s 后字符**逐字脱落**：连线先**缩短**
（自由端从圆点滑向字符）→ 再**散开**，随风加速飘向画面远方（风速渐强 + 蛇形
飘摆 + 浮力），拖尾连线自由端弹簧滞后。随后落幕并无缝循环（总长 10s）。

## 时间轴

| 时刻 | 事件 |

| 0.7 ~ 1.6s | **少量字符（16%）提前脱落**，移动途中即开始飘散 |
| 2.0s 起 | **分批错峰放行**：每 0.15s 一批（≤30 个，同时飘散 ≤380）：连线 0.45s 内缩短 → 释放 |
| 释放后 | 初速度 vx∈(3,5) vy∈(-12,-2) ±45° 偏转 → 风速 2s 内爬升至 7px/帧，蛇形飘向远方 |
| 释放后 1.8~2.9s | 字符淡出消散 |
| 1.6 ~ 3.2s | **右下角两句歌词淡入**（DOM 层，静态不飘散），保持至落幕 |
| 10 ~ 11s | 落幕淡出 → 循环重置（右下角歌词同步淡出） |

## 整圈铺满算法

1. 量出行内字符宽度，单遍超长时按环缩字号；
2. 以该行为单元**循环追加**，字距取 arcGap 随机值，直到铺满周长（至少一整遍）；
3. 剩余弧长归一化进字距，Σ(字宽+字距) = 周长，首尾严丝合缝；
4. 行距**内紧外松递进**（内环距可小于字号形成重叠），总高超画布时整体压缩。

## 飘散三段式

1. **附着**：字符在环上旋转，连线 = 圆点→字符；
2. **缩短**（0.45s）：自由端从圆点平滑滑向字符，线长 → 0，字符轻颤；
3. **散开**：释放初速度，风速渐强把字符带向远方，自由端弹簧滞后呈拖尾。

## 分批错峰放行（状态机）

每个字符处于状态机 `0 附着 → 1 缩短 → 2 飘散 → 3 消散`。
所有字符按期望脱落时刻（detAt）排入放行队列；每 `batchGap`（0.15s）放行
一批（≤`batchSize` 30 个），且**同时处于脱落/飘散状态的元素数不超过
`maxConcurrent`（380）**——有元素消散后才放行下一批，形成一波接一波
陆续飘散的节奏，而非一次性全部启动。

**注意**：分批节流的吞吐 ≈ batchSize/batchGap = 200 字/s，且受 maxConcurrent
× 消散速率双重限制。字符总量过多时（旧版约 1300 字）排队排不完，导致落幕时
仍有字符未飘散——两条解法：① 控制字符总量（perLine / arcGap / 歌词行数），
② deadline 强制放行保险兜底。当前配置约 250 字，主力窗口内即可放行完毕。

## 性能优化（保持视觉不变）

1. **字形精灵缓存**：唯一（字符×字体×字号）组合离屏预渲染一次（含深蓝错位底），
   逐帧 `drawImage` 代替逐字 `fillText`（约 250 字 × 2 遍 → 250 次位图拷贝）；
2. **天空离屏缓存**：渐变+光晕只在 setup/resize 画一次，逐帧 `drawImage` 代替
   每帧两次全屏渐变填充；
3. **连线分桶合批**：按透明度（0.05 步长）分桶，每桶合并为一条 path 一次 stroke；
4. **状态机早退**：已消散（state 3）字符后续帧完全跳过更新与绘制；
5. 实测（无头 Chrome 软渲染）：满环与飘散阶段均稳定 **60.5 fps**（优化前 2.5~6.5 fps）。

## 偏离规范的说明

AGENTS.md 约定"诗句用 DOM 层排版"，但本作品环上文字需要逐字符旋转、飞行、拖尾，
DOM 无法实现，故环上文字用 canvas 绘制（用户明确要求 p5.js 实现逐字符动画）。
右下角两句静态歌词不需要逐字符动画，**按规范回归 DOM 层排版**（pointer-events:none 叠于 canvas 上）。
深色底基准 #0a0e21 由用户显式要求改为新海诚风明亮蓝色。
