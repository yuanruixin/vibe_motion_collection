# 乌鸦啄月 · The Crow Pecking the Moon

> 参考图：黛青夜幕上，一轮**已被啄缺**的淡黄月亮，右缘缺口处立着一只乌鸦剪影；
> 月屑化作星星坠落，海面上**已有一捧星堆**。
> 本作品为 16s 无限循环：月亮**初始即残缺**、星堆**初始即存在**；
> 乌鸦继续小口啄食（每口都是小咬痕）→ 月屑成星坠落 → 落进既有星堆 →
> 末幕新咬痕愈合回初始残缺态、新落星隐去，无缝衔接。

## 时间参数（唯一事实来源，改动画先改此表）

| 参数 | 值 | 说明 |
|---|---|---|
| peckStart / peckGap / peckCount | 2.0s / 0.72s / 11 | 啄击时刻表：2.0 → 9.2s |
| 单次啄击动作 | 预备 -0.16s → 上啄 0.10s → 回收 0.32s | 头部绕颈轴旋转，喙朝左上 |
| 小咬痕 | **半径 6–9**（一口一小点），啄击后 0.16s easeOutCubic 弹开 | 沿基础缺口下沿 φ 60°→150° 排布，把缺口向下啃深一点 |

| 碎片数量 | 每次啄击 1–2 颗，共约 16 颗 | 最后一颗落海 ≤ 12.6s，早于 resetT |

| 既有星堆 | ≈ 55 颗，正弦堆形，全程驻留 | 闪烁频率取 `TWO_PI·k/16` 保证循环安全 |
| 新落星 | 叠加在既有星堆上，末幕 ×(1-fr) 淡出 | — |
| 末幕复位 | 13.0 → 16.0s：新咬痕 ×(1-fr) 愈合回**初始残缺态**；新落星/涟漪淡出；乌鸦回 idle | t=16 与 t=0 状态完全一致 |

## 循环安全约定

- 一切随时间连续的量（星星闪烁、波线相位、乌鸦 idle 摇摆、眨眼）角频率必须取 `TWO_PI·k/LOOP`（k 整数）。
- 碎片/碎屑只存活于自身时间窗内（用 `dt = t - 出生时刻` 表示），天然循环安全。
- 基础缺口与既有星堆是"初始状态"，不参与复位；只有本循环新增的咬痕与落星参与愈合/淡出。
- 调试：`?t=8.0` 可冻结在任意时刻截图验收。

## 验收清单
